使用帮助

常见问题解答与联系方式。

如何扫描一个文件夹？

打开「空间分析」，点击「选择扫描位置」，再通过 macOS 标准文件选择器选择目录。DeepClear 会在本机完成分析，并按大小列出文件。

扫描很慢时可以暂停吗？

可以。点击工具栏上的「暂停」按钮即可随时中断扫描，点击「继续」从上次位置恢复，已扫描的数量会完整保留。

如何删除文件？

在“大文件”中选择文件，或使用“文件浏览”中的废纸篓按钮。个人文件只会移入废纸篓，可以从 Finder 恢复；“智能清理”永久删除缓存前会再次确认。

为什么“智能清理”需要 Home 文件夹权限？

Mac App Store 沙盒要求您明确选择应用可以访问的目录。DeepClear 会将权限保存为安全作用域书签，并且绝不会请求管理员密码。

如何显示隐藏文件？

在“文件浏览”中勾选「包含隐藏项目」，DeepClear 会重新分析已选择的目录并包含隐藏项目。

DeepClear 会把我的文件信息上传到网络吗？

绝对不会。DeepClear 是纯本地工具，没有任何网络请求，不含分析 SDK，也没有服务器端组件。详情请参阅隐私政策。

支持哪些 macOS 版本？

DeepClear 需要 macOS 12 Monterey 或更高版本，同时针对 Apple Silicon 和 Intel Mac 进行了优化。

列宽可以调整吗？

可以。将鼠标悬停在两列之间的分隔线上，光标会变为左右箭头，按住并拖动即可自由调整宽度，最小宽度为 200pt。

还有其他问题？

请在 GitHub 提交问题，并附上 macOS 版本和简要问题描述。
