Privacy Policy

Last updated: January 1, 2025

This Privacy Policy describes how DeepClear ("we", "us", or "our") handles information when you use our macOS application ("App"). We are committed to protecting your privacy. In short: DeepClear collects no personal data whatsoever.

1. Information We Do Not Collect

DeepClear does not collect, store, transmit, or share any of the following:

  • File names, folder names, or file paths on your device
  • File sizes or metadata
  • Personally identifiable information (name, email, Apple ID, etc.)
  • Device identifiers, IP addresses, or location data
  • Usage analytics or crash reports sent to a third-party server

2. Local File System Access

The App requests access to folders you explicitly select via the macOS file picker. This access is used solely to read file and directory metadata (names, sizes, modification dates) and display it within the App. No data is ever read outside the folder you choose, and no data is written to your disk except when you explicitly delete a file (which moves it to Trash).

3. Administrator Privileges

When deleting a file or folder that is protected by the macOS sandbox, the App may request administrator credentials via a standard macOS system prompt. This elevated privilege is used only for that specific delete operation and is not stored, logged, or transmitted in any way.

4. Network Activity

DeepClear makes zero network requests. The App has no server-side component, no analytics SDK, and no third-party libraries that communicate with the internet.

5. Third-Party Services

We do not use any third-party services, SDKs, or frameworks that could collect data.

6. Children's Privacy

DeepClear does not collect any information from anyone, including children under the age of 13.

7. Changes to This Policy

If we ever change this policy, we will update the "Last updated" date above and post the new policy at this URL. We will never introduce data collection without publishing an updated policy.

8. Contact

If you have any questions about this Privacy Policy, please open an issue on our support page or contact us at support@deepclear.app.
