Support

Frequently asked questions and contact information.

How do I scan a folder?

Click the Select Directory button in the top toolbar, then choose any folder. DeepClear will start scanning immediately and display all contents sorted by size.

Can I pause a long scan?

Yes. Click the Pause button at any time. Click Resume to continue from where you left off. The scanned count is preserved.

How do I delete files?

Right-click any file or folder in the column view and choose Delete. Items are moved to Trash so you can recover them from Finder if needed.

Why does it ask for my password when deleting?

Some system folders are protected by macOS. When the normal deletion fails, DeepClear asks for your administrator password via a standard macOS prompt — this is the only way to delete those items. Your credentials are never stored or transmitted.

How do I show hidden files?

Check the Show Hidden Files checkbox in the toolbar. The columns refresh immediately without re-scanning.

Does DeepClear send any data to the internet?

No. DeepClear is entirely local. It makes zero network requests. See our Privacy Policy for full details.

Which macOS versions are supported?

DeepClear requires macOS 12 Monterey or later. It is optimised for Apple Silicon and Intel Macs.
