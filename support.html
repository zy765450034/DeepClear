Support

Frequently asked questions and contact information.

How do I scan a folder?

Open Space Analysis, click Choose Location, and select a folder in the standard macOS picker. DeepClear will analyze it locally and sort the largest files by size.

Can I pause a long scan?

Yes. Click the Pause button at any time. Click Resume to continue from where you left off. The scanned count is preserved.

How do I delete files?

Select a file in Large Files or use the trash button in File Browser. Personal files are moved to Trash so you can recover them from Finder if needed. Smart Cleanup asks again before permanently deleting selected caches.

Why does Smart Cleanup ask for Home folder access?

The Mac App Store sandbox requires you to explicitly choose the folder an app may access. DeepClear stores this permission as a security-scoped bookmark and never asks for an administrator password.

How do I show hidden files?

Turn on Include Hidden Items in File Browser. DeepClear will repeat the selected-folder analysis with hidden items included.

Does DeepClear send any data to the internet?

No. DeepClear is entirely local. It makes zero network requests. See our Privacy Policy for full details.

Which macOS versions are supported?

DeepClear requires macOS 12 Monterey or later. It is optimised for Apple Silicon and Intel Macs.

Still need help?
